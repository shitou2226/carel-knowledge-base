# CAREL c.mask多语言文本导入导出

## 本文解决的问题

将c.mask画面文本导出为翻译表，添加俄语文本后导回。以下步骤来自没有音轨的原始附录，已按关键画面核对。

## 前置条件与步骤

1. 使用工程副本，确认终端中已有待翻译文本和语言列表。25秒画面在Language Editor添加语言，50秒可见Russian [RU]。
2. 通过语言导出流程取得翻译表。75秒画面明确显示Translations_UNICODE工作表及Context/Id、各语言列；保留行与标识对应。
3. 在目标语言单元格输入译文。100–125秒示例将Hello world转换为Привет мир!，画面显示Arial Unicode MS字体。
4. 150秒回到c.mask的Import入口，按录屏导入文本。190秒终端预览可见俄文Привет мир!。[俄语翻译附录（无音轨）](../09-%E8%A7%86%E9%A2%91%E8%AF%BE%E7%A8%8B%E7%AC%94%E8%AE%B0/0411_%E4%BF%84%E8%AF%AD%E7%BF%BB%E8%AF%91%E9%99%84%E5%BD%95%EF%BC%88%E6%97%A0%E9%9F%B3%E8%BD%A8%EF%BC%89.md#%E7%94%BB%E9%9D%A2190%E7%A7%92)

## 输入与预期结果

输入为保持Context/Id和行映射的语言翻译表；录屏结果是在终端预览显示目标文本。该结果属于课程示例，尚未对本机用户工程执行。

## 常见错误与待核实

改动表的上下文/标识、使用不包含目标字符的字体、导入到错误终端或语言列，都会破坏文本映射或显示。当前4.4.22具体菜单和字体范围需在批准的测试工程确认，不把视频中的字体选择当成所有设备的通用配置。
