# CAREL 函数与功能块实例

## 本文解决的问题

选择函数或有状态的功能块，解释为什么同一个功能块需要多个实例。

## 资料确认的区别

| 对象 | 函数 Function | 功能块 Function Block |
|---|---|---|
| 实例 | 没有实例 | 调用实例 |
| 局部数据 | 不从一次调用保存到下一次调用 | 每个实例有自己的局部数据，跨周期保留 |
| 输出 | 一个返回参数，基本数据类型 | 可以有多个输出 |
| 调用限制 | 专门的 Functions 页禁止递归，并说明函数不能调用 FB | 可以调用函数或其他 FB |

## 应用例子

纯输入到输出的计算可先考虑函数；需要保存回差状态、计时或累计状态时，选择与需求相符的 FB 实例。后者是根据实例规则的设计建议，具体计时块参数需查目标库。

## 常见错误与原文差异

Function_Blocks 页笼统写“任何 POU”可调用 FB，而 Functions 页专门写函数不能调用 FB。此处保留两处表述；使用函数时按专门限制处理，不将“任何 POU”扩大解释。实例状态保持不等于断电保持，掉电行为还需 Retain 等配置。

## 待核实

实际工程所用库及 FB 版本、目标运行时的具体行为。
